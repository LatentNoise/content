Content 0.3.0 is the release that puts Content on PyPI — and the first whose
notes were written with the code, reviewed in the same tree, and published by
the tag itself.

## Install everything with one command

The three packages are live on PyPI, published through Trusted Publishing
(OIDC — no stored tokens anywhere):

```bash
uv tool install content-cli     # the `content` command
uv tool install content-mcp     # the MCP server for Claude, Cursor, agents
pip install content-sdk         # the typed Python client
```

The release-attached wheels remain for air-gapped installs, beside the
Chromium extension zip and the `SHA256SUMS.txt` covering every asset.

The full stack now installs without cloning anything, from the published
Docker images:

```bash
mkdir content && cd content
curl -fsSLO https://raw.githubusercontent.com/LatentNoise/content/main/deploy/docker-compose.yml
curl -fsSL -o .env https://raw.githubusercontent.com/LatentNoise/content/main/.env.example
docker compose up -d
```

## Names, refined

The naming engine's proposals get two finishing touches, applied identically
to the prefilled suggestion and to the server's own default naming:

- a colon used as a separator keeps its meaning in filenames:
  `twenty one pilots: Stressed Out [OFFICIAL VIDEO]` now becomes
  **`Twenty one pilots - Stressed Out`** — instead of losing the colon to a
  bare space;
- the first word earns its capital only when it is entirely lowercase, so
  brand spellings like `iPhone` or `eBay` are never "corrected".

## Fixes

- `content --version` now answers with the installed wheel's real version —
  0.2.0 replied `0.1.0` from a stale constant that sat outside the release
  tooling's lockstep. The version now comes from the package metadata and
  cannot drift again.
- Release tooling: `make version-update` proposes the next patch and minor
  versions; `make version-tag` refuses to re-tag an already-released version
  and explains the two-step bump instead; publishing supports a per-package
  bootstrap mode (`only=`) for first-time PyPI projects.

## Upgrading

```bash
docker compose pull && docker compose up -d      # the engine and UIs
uv tool upgrade content-cli content-mcp          # the installed tools
```

No contract changes.
