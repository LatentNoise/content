# Invariants

Properties that must **always** stay true. A change that breaks one is a
structural decision (a stop condition). Every invariant lists its rationale, the
component that guarantees it, and the existing verification.

> References: the domain and the state machines are described in
> [../domain.md](../domain.md); the public contract in
> [../contract.md](../contract.md). *(Both files will be relocated under
> `docs/architecture/` during a later tidying pass.)*

---

**INV-001 — Separation of the four concepts.**
`GenerationRequest` (intent) ≠ `ExecutionPlan` (strategy) ≠ `Job` (execution)
≠ `Artifact` (result). None is conflated with another.
*Rationale:* the contract stays stable while the internals change.
*Guaranteed by:* distinct types/modules (`domain/request.py`, `plan.py`,
`job.py`); an artifact is a *record*, written by the executor and read from the
store, with no domain model of its own (D-08). *Verified by:*
`test_contract_validation`, `test_planner`, `test_executor`.

**INV-002 — The public contract names no tool or provider.**
The one deliberate exception: `preferences.providers` (logical families).
*Rationale:* tools are interchangeable.
*Guaranteed by:* `domain/request.py` (no `yt-dlp`/`ffmpeg`/`ollama` in the
schema). *Verified by:* review + `test_contract_validation`.

**INV-003 — The domain is independent of all I/O and all frameworks.**
`content/domain/` imports neither FastAPI, nor SQLite, nor a provider.
*Rationale:* testability, substitutability.
*Guaranteed by:* the absence of I/O imports in `domain/`. *Verified by:* the
domain suite runs without network or DB.

**INV-004 — Every state transition goes through the state machine.**
No free-form `UPDATE status`: everything goes through `ensure_job_transition` /
`ensure_step_transition`. An unlisted transition raises.
*Guaranteed by:* `domain/job.py` + `store.transition_job`. *Verified by:*
`test_job_state`.

**INV-005 — A registered artifact always has its content (write-then-register).**
The file is promoted into `artifacts/` **before** the DB insert.
*Rationale:* a crash never leaves a row without bytes.
*Guaranteed by:* `executor._register_products` + `storage.promote_artifact`.
*Verified by:* the `reuse_existing` tests (including a corrupted cache).

**INV-006 — The event journal is append-only and sequenced per job.**
A strictly increasing `sequence`, never an `UPDATE`.
*Rationale:* replayability (SSE, stream resumption).
*Guaranteed by:* `store.append_event` under `BEGIN IMMEDIATE`. *Verified by:*
`test_operations` (SSE), `test_executor`.

**INV-007 — A job is never processed twice at the same time.**
The claim is atomic.
*Guaranteed by:* `store.claim_next_queued` (`BEGIN IMMEDIATE`). *Verified by:*
implicitly (the claim marks it `running`); **not covered by a concurrency test**
(see discoveries).

**INV-008 — A terminal state never transitions.**
`succeeded`/`partially_succeeded`/`failed`/`cancelled` are final; a `retry`
creates a **new**, linked job (`retry_of`).
*Guaranteed by:* `_JOB_TRANSITIONS` + the `retry` endpoint. *Verified by:*
`test_operations` (retry), `test_job_state`.

**INV-009 — No raw secret circulates.**
The contract carries only **references** (`credential_id` / `session_id`), never
a secret; neither in events, logs, snapshots nor responses.
*Guaranteed by:* `domain/request.py` (`SourceAuth`). *Verified by:*
`test_contract_validation` (auth requires a single reference).
*Note:* server-side resolution of `credential_id` will be introduced at the
cookies/auth milestone **without** letting a secret into the contract.

**INV-010 — Artifact filenames are generated by the backend.**
Never supplied by the client.
*Rationale:* security (no overwrite/traversal).
*Guaranteed by:* `storage.sanitize_filename` + the naming inside the executor.

**INV-011 — External processes: an argument list, never a shell, a mandatory timeout.**
Cooperative cancellation (terminate → kill after 5 s), stdout/stderr kept
separate.
*Guaranteed by:* `execution/process.py` (a single runner). *Verified by:*
`test_resilience` (missing binary, timeout).

**INV-012 — `file` sources stay under the allowed roots.**
Symlinks and `..` are resolved before the check; refused by default if no root
is configured.
*Guaranteed by:* `providers/ffmpeg.check_path_allowed`. *Verified by:*
`test_file_sources` (traversal, symlink, missing root).

**INV-013 — A job's normalized request is immutable after submission.**
*Rationale:* provenance and reproducibility.
*Guaranteed by:* the `jobs.request` column (JSON) + snapshots; no update path.
*Verified by:* the absence of any modification API.

**INV-014 — "Valid but not implemented" ≠ "invalid".**
A reserved type/scope/option is **structurally accepted** then rejected at
feasibility time (`*_not_supported`), never conflated with a schema error.
*Guaranteed by:* `planning/planner.py`. *Verified by:* `test_planner`,
`test_api`.

**INV-015 — Planning is deterministic and content-addressed.**
The same request/analysis/environment → the same plan. A step's **signature**
(operation + provider + resource identity + options + the dependencies'
signatures) is **independent of the identifiers chosen by the client**.
*Guaranteed by:* `_PlanBuilder` (`planning/planner.py`). *Verified by:*
`test_planner` (determinism), `test_operations` (reuse independent of the ids).

**INV-016 — The database is the source of truth.**
The filesystem carries the bytes and the snapshots; a divergence is detectable
by checksum. *Accepted constraint:* the DB and the FS share the same volume (the
plan only exists in `snapshots/plan.json`).
*Guaranteed by:* `persistence/store.py` + `storage/layout.py`.

**INV-017 — Storage boundaries: `tmp != work != artifact != cache`.**
Four families, four lifecycles; the `tmp`/`work` cleanup never touches an
artifact; paths controlled by the backend (anti-`..`); atomic publication; a
cross-job cache that can be switched off (default off, enabled for HomeTube —
ADR 0010). Details and sub-invariants
(INV-STORAGE-001..010) in [docs/storage.md](../storage.md) (ADR 0009).
*Guaranteed by:* `storage/paths.py` + `storage/layout.py`; *verified by:*
`test_storage`.

## Invariants **targeted but not yet guaranteed** (debt, see discoveries)

- **INV-100 (target)** — Every accepted field of the contract has an effect or is
  rejected (`*_not_supported`): the "honour it or reject it" policy. *Violated
  today* by ~10 inert fields (`mode:sync`, `retention`, `optimize_for`, `hints`,
  `auth`, `delivery`…). To be restored block by block.
- **INV-101 (target)** — A reused artifact comes from a job that actually
  succeeded. *Today* `find_reusable_artifact_group` does not filter on the source
  job's status.
